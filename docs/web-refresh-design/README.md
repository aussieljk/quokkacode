# Website refresh (2026-11-03)

The website had fallen behind the Mac and iPhone apps (a honey accent, a
timestamp under every message, raw tool lines like `quokkacode: end_turn`,
no folded turns or cards). Mike expects it to be used mostly for sharing,
so three directions were mocked up around who opens it:

1. `1-mac-in-a-tab`: everything looks like the Mac window.
2. `2-shared-write-up`: the shared page reads like a short write-up, with
   an outline of the asks; Mike's own view is the Mac's, with a Share
   button that previews the link's unfurl.
3. `3-phone-first-share`: the shared page looks like the iPhone app, with
   a big share sheet for Mike.

Mike picked **B**. `built-*.png` are the build on sample data (dev
deployment), for comparing with `2-shared-write-up.png`. Render the
mockups with `render.sh`.
