Help with Quokka Code

It's just me making Quokka Code, so the best way to reach me is email: quokkacode@mikecann.app. Let me know what happened and whether it's the Mac or iPhone app (a screenshot helps loads), and I'll get back to you as soon as I can.

How do I pair my iPhone?

The iPhone app goes with Quokka Code on your Mac. On the Mac, run swift ios/scripts/pair-qr.swift in your Quokka Code folder and it shows a code. In the iPhone app, tap Scan the code and point it at the screen. If the link came another way, like a message to yourself, copy it and tap Paste a pairing link instead.

Can I try it without a Mac?

Ye, tap Look around with sample threads at the bottom of the first screen. They're made up and stay on the phone, and you can reply, approve and answer questions to see how it works. Leave the demo from the menu at the top left when you're done.

Why does it say my Mac is offline?

Quokka Code on the Mac checks in every so often, and the phone says it's offline when it hasn't heard from it for a few minutes, usually because the Mac's asleep. Anything you send waits and goes through when it's back.

The app says the server stopped accepting this phone

The phone's sign in code has run out or been cancelled on the Mac. Make a new one and pair again, the same way as the first time.

How do I stop using it on a phone?

In the iPhone app, open the menu, then Settings and Unpair this phone. If the phone's lost, cancel its sign in code on your Mac too and it stops working straight away.
